# HEC-RAS 2D Flood Modeling

## Project Overview
Hydraulic modeling of the Muncie and Bald Eagle Creek sites using HEC-RAS (2D Unsteady Flow).

## Workflow
*   **Simulation:** Configured unsteady flow boundary conditions and ran 2D flow simulations.
*   **Analysis:** Utilized RAS Mapper to calculate Maximum Water Surface Elevation (WSE) and flood depth.
*   **Visualization:** Exported flood depth rasters and contour polygons into QGIS, applying transparency and overlaying them onto OpenStreetMap basemaps to visualize infrastructure at risk.
